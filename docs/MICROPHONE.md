# Tab5 USB 麦克风

**简体中文** · [English](MICROPHONE.en.md)

适用源码版本：**0.13.0-dev.1 开发版，尚未发布**。最新公开下载仍为 [0.12.0](https://github.com/atovk/tab5-codex-micro/releases/tag/v0.12.0)，不包含本页的板载麦克风功能。本开发版已完成构建并刷入 Tab5；USB 采音、静音、增益与设置保留的实测范围见下文。

## 连接与使用

USB 提供名为 **Tab5 Microphone** 的标准 UAC1 输入，格式为 **16kHz、16-bit、单声道 PCM**。固件对板载两个麦克风通道取平均后输出单声道，未实现回声消除（AEC）或波束成形。电脑不需要安装本项目音频桥接或虚拟音频驱动。

1. 通过 Tab5 机身的 USB-C **数据口**连接电脑。
2. 在 macOS **系统设置 → 声音 → 输入**，或录音应用自己的输入列表中，选择 **Tab5 Microphone**。如果应用使用系统默认输入，需先选择该系统输入；按应用提示授予麦克风权限。
3. 在 Tab5 打开 **齿轮 → 麦克风 / Microphone**，检查电平、静音和增益。
4. 再按桌面语音映射使用 **Voice**。USB 音频连接、移动的电平或按下 Voice，都不能单独证明某个应用已经选择 Tab5 并正在录音。

USB 音频不依赖标题同步服务，可与 CDC 同步和原生 Micro HID 同时使用。Voice 键继续执行原生桌面映射，不自动切换音源。只接电源或仅通过蓝牙配对不会建立 Tab5 音频输入。

## 为什么暂不支持蓝牙麦克风

Tab5 的 ESP32-C6 提供的是 [Bluetooth LE](https://docs.espressif.com/projects/esp-idf/en/latest/esp32c6/api-guides/ble/overview.html)，没有 Bluetooth Classic；常见蓝牙耳麦的 [HFP 属于 Classic 配置文件](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-guides/classic-bt/profiles-protocols.html)。因此，不能直接通过 HFP 把 Tab5 变成电脑可选择的普通蓝牙耳麦麦克风。本项目也没有实现 LE Audio。

自定义 BLE 音频需要额外的电脑音频桥接；在 Mac 上还需要虚拟音频设备才能供录音应用选择。这会增加安装、运行和维护要求，因此本版先提供标准 USB 麦克风，暂缓蓝牙音频。

**原有蓝牙按钮、旋钮、摇杆、灯效和标题／聊天状态同步不受影响**，配对与自动重连仍按 [蓝牙指南](BLUETOOTH.md) 使用。仅蓝牙连接时，语音可继续使用电脑麦克风；需要 Tab5 麦克风时接上 USB 数据线并选择其输入。

## 电平、静音与增益

| 界面状态 | 含义 |
| --- | --- |
| USB ready／USB 已就绪 | USB 已连接，但主机未打开音频输入 |
| USB streaming／USB 音频传输中 | 主机已打开 USB 音频流，不标识具体消费音频的应用 |
| Monitoring／本机监听 | 麦克风页正在显示本机电平，不代表电脑收到音频 |
| Muted／已静音 | 本地麦克风静音，停止采集并使 USB 音频输出静音 |
| Computer muted／电脑已静音 | 主机对 USB 输入静音，需在电脑端解除 |

麦克风页提供实时电平和峰值、独立静音键，以及 **0–200%** 增益。**100%** 是正常数字增益；声音太小可适量增加，频繁到顶或失真时应降低增益或增大说话距离。它与扬声器音量分别设置，麦克风增益及本地静音会在普通重启和兼容 app-only 更新后保留。

USB 主机静音不覆盖独立的本地电平监测；设备上的取消静音也不能覆盖主机静音。离开麦克风页只结束本机监测，不中断主机已打开的 USB 输入。未静音的 USB 音频流开启时，界面提示音临时暂停，保存的扬声器音量不变。

## 采集与验证

只有主机打开 USB 输入或用户打开麦克风页监测时，固件才启用采集。本地静音停止采集。固件只处理短内存音频块，不把录音写入 Flash／SD，也不上传音频到网络。电脑收到音频后的录音、转写和联网行为由使用它的应用决定。

本开发版已通过 **376 项主机测试**并以 app-only 方式刷入同一台 Tab5。最终 USB 固件已完成以下实测：

| 项目 | 实测结果 |
| --- | --- |
| USB 输入 | macOS 枚举出 **Tab5 Microphone**，并通过它录得 16kHz 单声道音频及 997Hz 测试信号 |
| 本地静音 | 主机录音中连续 1 秒的采样全部为零，解除静音后恢复 |
| 主机静音 | macOS CoreAudio 静音后，主机录音中连续 1 秒的采样全部为零；设备的主机静音状态在静音与解除时均匹配 |
| 数字增益 | 同一测试音在 100% 增益时 RMS 约 620，200% 时约 1240，符合约两倍的幅度变化 |
| 设置保留 | 增益 155% 和本地静音在 app-only 更新后保留；验证后恢复为 100% 和未静音 |
| USB 逻辑重连 | 固件逻辑断开 USB 10 秒后，输入消失并以相同 UID 返回；CoreAudio 再次收到 31,232 帧 16kHz 音频并测得非零信号，原生 USB 恢复，蓝牙绑定保留 |
| 停止采集 | 主机关闭输入且未打开本机监测时，ADC 停止，空闲期间帧计数不增长 |
| 采集错误 | 此轮测试的音频读取错误计数为 0 |

这些结果确认了主机实际收到音频及静音／增益效果。**Codex 是否已选中该输入、是否开始录音或完成转写尚未验证**，仍需由实际应用确认；重连测试使用固件的 USB 逻辑断开，未测试拔线或掉电；最终版的语音音质、其他电脑与长时间使用也不在上述测量范围内。

## 从开发版源码刷入

以下命令仅适用于**包含 0.13.0-dev.1 麦克风实现的源码目录**；0.12.0 下载包和 `v0.12.0` 标签不包含本功能。按 [源码构建说明](../README.md#从源码构建) 准备环境后：

```sh
.venv/bin/python tools/prepare_platform.py
.venv/bin/pio run
.venv/bin/python tools/verify_device.py discover
.venv/bin/python tools/flash.py --port /dev/cu.usbmodemXXXX --skip-build --app-only
```

端口必须对应实际 P4 Tab5。**`--app-only` 仅用于已有兼容分区布局、完整有效标题字库且无需迁移的安装**；不改写的 NVS、绑定与字库可保留。首次安装、分区变更或字库缺失时按源码说明完整刷入。完整 factory 刷入会重置偏好与绑定；麦克风不改变标题字库分区地址。

## 排查

- **USB 输入未出现**：确认开发版固件、机身数据口和数据线；蓝牙配对不能代替 USB 音频枚举。
- **仅通过蓝牙连接时没有 Tab5 音源**：本版不支持蓝牙麦克风；接上 USB 数据线，或使用电脑麦克风。
- **有电平但应用无声**：检查是否实际选择 Tab5 Microphone、麦克风权限、两端静音和增益；设备电平不是桌面录音回执。
- **声音失真或有回声**：降低增益、增大说话距离或使用耳机。本版未实现 AEC、波束成形或降噪，不承诺通用音质或延迟上限。
- **提示音暂时消失**：未静音的 USB 音频流会暂停界面提示音；主机停止使用输入后恢复，保存音量不会被改写。
